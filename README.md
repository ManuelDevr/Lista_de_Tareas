# Lista de Tareas - v2.0

Aplicación web sencilla para gestionar tareas diarias con una interfaz moderna, animaciones suaves y persistencia local.

## Descripción del Proyecto
Esta app permite crear, completar y eliminar tareas desde una lista dinámica. También muestra un contador de tareas totales y completadas, más una barra de progreso que visualiza el avance.

## Tecnologías Utilizadas
- HTML5
- CSS3
- JavaScript
- Icons con Lucide icons

## Estructura del Proyecto
- `index.html` – estructura y contenido de la interfaz.
- `Css/Styles.css` – estilos del diseño responsivo.
- `Js/App.js` – lógica de la lista de tareas y `localStorage`.
- `Img/Icon.png` – icono de la página.
